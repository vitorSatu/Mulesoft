# 🔌 Mulesoft — Portfólio de Integrações

Portfólio de projetos práticos desenvolvidos para consolidar e demonstrar experiência com **Anypoint Platform**, **API-led connectivity** e boas práticas de integração no ecossistema MuleSoft.

Este repositório reúne implementações que cobrem desde fundamentos até padrões avançados de arquitetura de integração, com foco em clareza de design, documentação técnica e cobertura de testes.

---

## 👨‍💻 Sobre

Desenvolvedor MuleSoft com experiência profissional prévia em integrações CRM/Salesforce e gestão de grupos de acesso via Anypoint Platform. Este repositório documenta um plano de estudos estruturado de 6 semanas, aplicado na prática através de projetos reais.

**Stack principal:** Anypoint Studio · DataWeave · RAML/OAS · MUnit · CloudHub · API Manager

## 🗺️ Plano de Estudos

Este portfólio segue um plano estruturado de 6 semanas (5–10h/semana):

1. **Fundamentos do Anypoint Platform** e API-led connectivity
2. **Mule Flows, DataWeave** e conectores
3. **RAML/OAS** e design-first de APIs
4. **Error handling, batch processing** e padrões de integração
5. **Segurança, deployment** e boas práticas de configuração
6. **Revisão, testes MUnit**, projeto capstone e simulação de entrevista
